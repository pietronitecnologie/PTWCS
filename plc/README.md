# Blocchi PLC per il layer fisico di PTWCS

- `tia/SimIO.scl` – S7-1500 / PLCSIM Advanced: DB `SimIO` (ingressi simulati scritti da PTWCS,
  attivo e heartbeat), DB `In` (immagine ingressi usata dal programma) e `FB_SimIO` che sceglie
  tra ingressi reali e simulati con watchdog.

Istruzioni complete nel manuale: **Designer – Fisica** (`web/manual/designer-fisica.md`).
